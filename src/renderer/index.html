        Vorschau

        Bevor es losgeht

        Mit ASK Desktop arbeitet das Sprachmodell selbständig in einem Ordner auf deinem Laptop. Es kann dort Dateien lesen, neue Dateien schreiben, Programme ausführen und Dateien ändern oder löschen.

        Arbeite deshalb nur mit Kopien. Lege für jedes Projekt einen eigenen Ordner an und kopiere nur die Dateien hinein, die das Modell braucht. Wichtige Originale bleiben an ihrem Ort.

        Ordner in OneDrive oder SharePoint lassen sich nicht wählen, weil Änderungen dort sofort in die Cloud übertragen würden. Ausserhalb des gewählten Ordners kann das Modell nichts schreiben, lesen kann es aber auch andere Dateien auf dem Laptop.

        Was das Modell aus deinen Dateien liest, wird an ASK geschickt. Lege keine vertraulichen oder persönlichen Daten in den Ordner.

        Prüfe die Ergebnisse, bevor du sie abgibst oder weitergibst.
